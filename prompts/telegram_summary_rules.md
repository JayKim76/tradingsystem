# Telegram 요약 규칙

## 전송 조건
- Google Sheets 기록 **성공 후에만** 전송
- Sheets 기록 실패 시: 로그 기록 후 스킵 (재시도 없음)
- 전송 실패 시: `logs/YYYY-MM-DD_telegram_error.log`에 기록

---

## Daily 요약 (5~8줄)

**포맷**:
```
📅 {YYYY-MM-DD} 투자 브리핑

📊 시장: {시장국면 한 단어} | KOSPI {등락률}% | S&P500 {등락률}%
💱 환율: {USD/KRW} | 10Y: {미국금리}% | VIX: {VIX값}

🎯 오늘 핵심 신호
{가장 중요한 시장 신호 1가지 — 1줄}

💼 포트폴리오 변화
{섹터 그룹 기준 중요 변화 — 1~2줄. 변화 없으면 "특이사항 없음"}

⚠️ 즉시 확인할 리스크
{리스크 1가지 — 없으면 생략}

📋 오늘 주요 일정
{2~3개 이벤트}

📁 상세: reports/daily/{YYYY-MM-DD}.md
```

**규칙**:
- 총 5~8줄 유지. 이모지는 섹션 구분용으로만 사용
- 수량·평단·비중 수치 기재 금지
- "오늘 볼 것", "포트폴리오 중요 변화", "즉시 확인할 리스크" 세 가지가 반드시 포함
- 리포트 파일 경로는 마지막 줄에만 표기

---

## Weekly 요약 (6~10줄)

**포맷**:
```
📆 {YYYY} W{xx} 주간 포트폴리오 리포트

📈 수익률: 포트폴리오 {±X.X%} | 벤치마크 {±X.X%} | 초과 {±X.X%}

🏆 최고 기여: {ticker} {±X.X%}
📉 최저 기여: {ticker} {±X.X%}

🔍 Thesis 변화
{변화 있으면 종목+내용 1줄, 없으면 "없음"}

⚖️ 리밸런싱
{후보 종목 있으면 나열, 없으면 "불필요"}

🔭 다음 주 주요 촉매
{2~3개 이벤트}

📁 상세: reports/weekly/{YYYY-Wxx}.md
```

**규칙**:
- 총 6~10줄 유지
- 수익률은 소수점 1자리까지만 표기
- Thesis 변화가 없으면 해당 줄 생략 가능
- Watchlist 승격 후보 있으면 마지막 줄 앞에 추가 (1줄)

---

## 공통 규칙
- 메시지는 **한국어**로 작성
- HTML 마크업 사용 금지 (Telegram MarkdownV2 또는 plain text)
- 링크는 파일 경로만 표기 (외부 URL 포함 금지)
- 시각은 KST 기준으로 표기
