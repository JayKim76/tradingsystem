# 일일 투자 브리핑 Runbook

**실행 시각**: 매일 09:00 KST  
**출력 파일**: `reports/daily/YYYY-MM-DD.md`  
**투자자 프로필**: `data/investor_profile.md` 참조  
**보유 종목**: `data/portfolio.csv` 참조 (수량·평단 반복 금지 — 섹터 그룹과 thesis 중심으로)  
**관찰 종목**: `data/watchlist.csv` 참조

---

## Step 1 — 데이터 수집
다음 수치를 실시간 또는 전일 종가 기준으로 수집한다:

```
시장 지수 : KOSPI, KOSDAQ, S&P500, NASDAQ, Dow
금리     : 미국 10년물, 한국 3년물
환율     : USD/KRW, DXY
원자재   : WTI, Brent, 금 현물
변동성   : VIX
```

---

## Step 2 — 브리핑 프롬프트

아래 프롬프트를 Claude에게 전달한다. **포트폴리오 파일은 참조만 하고 수량·평단을 본문에 재기술하지 않는다.**

```
당신은 세인투의 개인 투자 비서입니다.
투자 스타일: Value / Quality / Cash Flow / Shareholder Return / Margin of Safety
주요 섹터: [한국] 반도체·금융·자동차·방산 / [미국] 금융·헬스케어·에너지·플랫폼
참조 파일: data/portfolio.csv (섹터 그룹 + thesis 참조), data/watchlist.csv

오늘 날짜: {YYYY-MM-DD}
수집 데이터: {Step 1 수치 삽입}

아래 구조로 reports/daily/{YYYY-MM-DD}.md 를 작성하라.
본문은 한국어로 작성하고, 항목 간 불필요한 서론을 생략한다.
```

---

## Step 4 — Google Sheets 기록
`docs/google_sheets_schema.md`의 `일일브리핑` 탭 스키마에 맞춰 아래 값만 기록한다:

| 컬럼 | 값 |
|------|----|
| 날짜 | YYYY-MM-DD |
| 실행시각_KST | HH:MM |
| 시장국면 | 문자열 (예: 리스크오프, 혼조) |
| 코스피종가 | 숫자 |
| 코스피1일등락률 | % |
| 코스닥종가 | 숫자 |
| 코스닥1일등락률 | % |
| S&P500종가 | 숫자 |
| S&P5001일등락률 | % |
| 나스닥종가 | 숫자 |
| 나스닥1일등락률 | % |
| 원달러환율 | 숫자 |
| 미국10년물금리 | % |
| 달러인덱스 | 숫자 |
| WTI | 숫자 |
| 금가격 | 숫자 |
| VIX | 숫자 |
| 강세섹터 | 쉼표 구분 (최대 3개) |
| 약세섹터 | 쉼표 구분 (최대 3개) |
| 핵심동인Top3 | 세미콜론 구분 (50자 이내) |
| 포트폴리오액션요약 | 30자 이내 |
| 오늘주요일정 | 세미콜론 구분 |
| 리포트파일 | reports/daily/YYYY-MM-DD.md |
| 생성시각 | ISO 8601 |

기록 실패 시 `logs/YYYY-MM-DD_error.log`에 기록하고 Telegram 전송을 스킵한다.
