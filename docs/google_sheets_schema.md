## 참고: 스프레드시트 권장 설정
- 각 탭의 1행: 헤더 (굵게, 배경 회색)
- 날짜 컬럼: 날짜 형식 지정 (YYYY-MM-DD)
- 수익률 컬럼: 숫자 형식 (소수점 2자리)
- 리포트파일 컬럼: 일반 텍스트 (링크 자동 변환 비활성화 권장)
- 데이터 행은 위에서 아래로 누적 (삭제 금지)
